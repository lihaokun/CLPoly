# 实际保留基行坐标的显式上界

日期：2026-10-16。

## 证明与实现

在[自然语言草稿](../../nl-proof/vanhoeij-eventual-separation.md) §4
补全对角 Gram 等式和每项估计后，新增
[VanHoeijRowBounds](../../lean/CLPoly/Refinement/VanHoeijRowBounds.lean)。

1. 从实际缓存 `G=L D Lᵀ` 的对角项取得物理行平方和等式。
2. 单位下三角 L 的对角为 1、右侧为 0；左侧由实际 size reduction
   控制在 1/2。正的 GS 范数和已有保留范数界控制每个非零项。
3. 对实际返回行、实际保留前缀证明平方和≤`N·2^N·B`。
4. 任意物理坐标的平方≤整行平方和，得到整数绝对值界
   `N·2^N·B+1`。定理直接读取原返回数组中的该坐标。

这里 B 是调用方给出的非负平方 cutoff；跨不同 Hensel 精度的统一
输入界还须由参数选择与规范格维数上界提供，不能省略这一步。
