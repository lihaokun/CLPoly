# van Hoeij 三版本分阶段性能记录

日期：2026-10-16。修复实现提交：`2673cbe3571d7cf0b5af21a4766a6bea1381ad86`。

## 结果与限制

修复版六个输入组合、共 18 次运行全部返回精确已知的不可约因子，并与
固定 FLINT 3.1.2 的同输入结果一致；每次完整证书计数为 1，独立计时器
记录 LLL 调用非零、内外 Zassenhaus 调用均为零。

三版本共 18 个组合：15 个完成三次，3 个旧版组合被 300 秒限时截断。
总计 47 个已完成样本均通过准确因子及 FLINT 对照。截断项保留已完成
样本，未完成项没有中位数，不以超时推断算法错误或补填结果。

本任务的 Lean B2B 解释器在测量期间挂起，之后已自动恢复。但期间
观测到系统服务、Godot、Android 模拟器等其他负载，主机并非空闲，
高次样本出现明显波动。以下墙钟数字只描述本轮观测；不能据此给出
稳定加速比例，也不能声称复现了用户未提供原始输入的约 50% 退化。

轻输入 r=24 的修复版观测中位数比 safety-net 版高约 11%–12%，
r=32 低约 13%–21%。这不是所有输入都更快的结论。高次 r=32 的两个
旧版首个样本均未在 300 秒内完成，而修复版完成全部三次；路径计数
确认修复版通过格证书完成了非平凡重组。

## 固定条件

- 主机：Apple M3，8 个物理/逻辑核心，arm64 Darwin。
- 编译：Nix Clang 19.1.7，`-std=c++17 -O2`；三个版本均启用
  `CLPOLY_PROFILE`、`CLPOLY_PHASE_BENCH`、`CLPOLY_FLINT_REFERENCE`，
  修复版另启用只检查结果和打印计数的 `CLPOLY_CERTIFICATE_BENCH`。
- 依赖：GMP 6.3.0、Boost 1.87.0、MPFR 4.2.1、FLINT 3.1.2。
- 素数 p=97；r=24/32。二次族由正系数二次多项式构造，判别式为负；
  高次族的两个因子满足 p=2 的 Eisenstein 判据。输入因子的不可约性
  来自构造，不能用输出乘积相等替代。
- 有限域分解使用固定种子 42；三个版本的有限域分解和稠密运算源码
  哈希一致，同一编译器下得到相同模因子顺序；FLINT 接收同一模因子列表。
- 每个版本/输入族/r 独立启动，内部重复三次；每个组合限时 300 秒。
  非首一族反转版本次序。没有预热或主机负载隔离保证。
- 在基准副本插入相同 RAII 计时器；生产算法未加入计时范围改动。
  三个版本均应用同一 `realroot` 模板定义顺序修复，以通过 Clang 解析。
