# van Hoeij 完成证书：修正后的证明草稿

2026-10-15。状态：草稿；下述义务尚未全部连接到严格生成模型，不能宣称新 C++ 已获端到端形式验证。

## 前提与目标

f 是正首项、本原、无平方的整数多项式，模 p 保持次数且无平方。h_i 是两两不同的模 p 不可约因子的首一 Hensel 提升，lc(f)∏h_i=f mod m，m=p^a。每个整数不可约因子 g 对应非空且互不相交的模因子支持 S_g，其 indicator 为 e_g。

目标：从实际格构造、整数幺模行操作、安全保留的行和完整候选验证推出输出不可约；不能接收输出不可约性作为前提。

## 1. CLD 与系数界

令 C_i 是 f*h_i'/h_i mod m 的对称代表。对真因子 g，Σ e_g[i] C_i ≡ (f/g)g' mod m。该等式可由乘积求导与 Hensel 支持对应推出。

设 n=deg f，H=n·2^(n−1)·||f||₁。将 f 在 C 上写作 lc(f)∏(x−α)，则 (f/g)g' 是 lc(f) 乘以至多 n 个“略去一个根”的乘积之和。每个略根乘积的任一系数绝对值最多为 2^(n−1)∏max(1,|α|)。所以每个系数最多为 H，使用 Mahler(f)≤||f||₁。首项系数会在对数导数中抵消，因此不要求 g 首一。

Lean 路径：已有 Polynomial 的分裂、derivative_prod、系数乘积界、mahlerMeasure_mul 和 mahlerMeasure_le_sum_norm_coeff；具体略根系数界仍需展开并验证 API。

形式化采用等价的系数卷积路径，避免手动索引根：令 deg(g)=d+1、deg(h)=e，h=f/g。由 `norm_coeff_le_choose_mul_mahlerMeasure`，g' 的第 k 项界为 `(k+1) choose(d+1,k+1) M(g) = (d+1) choose(d,k) M(g)`（`Nat.succ_mul_choose_eq`）。乘以 h 后用 `coeff_mul` 的反对角和与 `Nat.add_choose_eq`，得到第 j 项界 `(d+1) choose(d+e,j) M(g)M(h)`。再用 Mahler 乘法性、choose≤2^(d+e)、d+1≤n 及 Mahler≤L1，即为 H。以上所列 API 已在当前 Mathlib 源码核实。非恒定 g 是真不可约因子的前提；h 常数仍适用。

### 实际 CLD 的模环语义

旧 generatedCldElement_toPolyMod 额外要求提升因子在整数上整除 f，这不适用
于一般 Hensel 提升结果。新桥接只在 ZMod(m)[X] 中操作：物理模除法返回
空余式，现有原始执行定理给出 q·h=f mod m。h 在模环首一，因此
f /ₘ h=q，直接由 monic 乘法除法消去（不需要 m 为素数，允许零因子环）。
实际导数数组映射为 derivative(map h)，系数约化保持模映射，乘法和对称
约化也保持模映射，所以最终 CLD 正是 `(map f /ₘ map h)*derivative(map h)`。
这里不假设整数整除；后续仍需由真因子支持乘积的求导得到 CLD 子集和。

子集乘积的代数步骤在任意交换环中证明：设支持内的首一多项式列表为 L，
F=H·prod(L)，则 Σ_{h∈L}(F /ₘ h)h'=H·(prod(L))'。对 L 归纳，空列表为
0=0。首项 h 的商是 H·prod(tail)，尾项整体应用 H*h 作为补因子的归纳
假设，最后展开 derivative_mul 并整理交换环等式。只用首一除法消去，
不使用域上的除法或无零因子条件，所以适用于 m=p^a。

### 完整物理 CLD 循环

对实际 cldPolysLoop 的 active.size-index 归纳，保持 result.size=index
及已有每个位置的三项性质：规范稀疏表示、模环 CLD 语义、系数的对称
半模数界。每个成功步骤依次拆开真实模除法、求导、系数约化、乘法与
对称约化执行；乘法规范化提供规范输入，对称约化保持规范性并给出界。
模环语义使用新 generatedCldElement_modular，不再使用整数整除前提。
push 保持已有位置并在末尾写入已验证的 cld，最终长度和全部位置性质
一起返回。空 active/result 是初始不变式的退化情形。

对支持下标列表，把每个实际 CLD 输出映射到模环，逐项替换为上述语义；
若模 f 等于补因子乘支持内首一因子之积，直接应用任意交换环中的乘积
求导公式。若整数 f=h*g，且模 g=常数 c·支持乘积，则补因子取
map(h)·C(c)，利用导数与映射交换、常数导数为零，得到实际 CLD 子集和
等于 map(h*g')。这个组合不要求 g 不可约，只要求正确的支持乘积关系；
后者必须由 Hensel 支持对应证明产生。

## 2. 截断后的格包含全部真 indicator

### 物理规范矩阵的不变式

新矩阵证明单独放入 VanHoeijLattice 模块。设 r=cld.size，已经加入 j 列，
矩阵大小为 r+j、每行等长。前 r 列的 (row,column) 项是 scale·δ；后 j
列的前 r 行是按螺旋顺序读取的 CLD 系数，其余行是 modulus·δ。
此项公式不依赖 j，只由 j 限定有效下标，适合循环归纳。

初始 makeInitialMatrix 给出 scale 对角阵。追加一步时对旧/新行与旧/新列
分四种情况：旧行旧列由 push 与 set 的异下标性质保持；旧行新列由填列
定理给出 CLD 值或零；新行旧列为零；新行新列为 modulus。
沿 buildCldMatrixLoop 的 target-added 递减归纳，成功执行保留该不变式。
矩阵因而上三角，对角元素为 scale 或 modulus；两者非零时，行列式是
非零对角元素之积，得到实际 LLL 输入所需的满秩性质。

由同一逐项公式，任意原始整数坐标 a 的因子坐标列 k<r 等于 a_k·scale，
因为该列仅第 k 行非零。范数界把 Fin(r+j) 的求和拆成前 r 项和后 j 项。
前 r 个 a_k∈{0,1} 时每项平方≤scale²；后 j 个实际数据坐标若绝对值≤T，
则每项平方≤T²。相加得到 r·scale²+j·T²。后 j 项的绝对值界必须再由
模 CLD 同余和共同截断推导，不能由候选不可约性假设提供。

只在 H<m 时尝试 CLD。对任一被选系数，设 a 为真实 CLD 系数，C_i 为对称代表，则 Σe_i C_i=a+z m。由 |C_i|≤m/2、|a|≤H<m、r≥2 得 |z|<r/2+1≤r（r=2 时严格小于 2），故 |z|≤r。

任取正整数 D，设 C'_i=floor(C_i/D)，m'=floor(m/D)。写 C_i=D C'_i+u_i、m=D m'+v，0≤u_i,v<D。则

```
Σ e_i C'_i − z m' = (a − Σ e_i u_i + z v)/D
```

绝对值至多 ceil(H/D)+2r，记作 T。因此格 `[sI | C'; 0 | m'I]` 含有向量 `(s e_g, e_g C'−z m')`，平方范数≤r s²+J T²=B。D 的选择只影响性能；增加 D 或限制虚拟模数位数不改变上述推导。所有列共用一个 D、m'。

严格整数算术桥接使用稍弱但更通用的界 |C_i|≤m：支持至多 r 个元素，
故 |ΣC_i|≤r·m。由 |a|≤H<m、ΣC_i=a+z·m 和整数 z，得到 |z|≤r，
无需依赖精确的 m/2 对称端点。逐项使用 D·(C_i/D)+C_i%D=C_i，并对模数
使用相同恒等式，推出截断残差等式。各余数在 [0,D) 内，余数和≤rD；
`H≤D*((H+D-1)/D)` 则由同一除余恒等式及余数<D推出。将这些真实除余
性质代入已有 truncated_cld_coordinate_bound，得到实际 floor 值的残差界。

组合时显式定义 a：前 r 项为支持集合 S 的 0/1 指示值，其余项为各列进位
的负值。规范矩阵的数据列公式化为 Σ_{i∈S} floor(C_i/D)−z·floor(m/D)，
因为不属于 S 的因子项为零。将上段残差界代入物理范数定理得到完整短向量。
前提中的 CLD 系数、支持集合及同余应由 Hensel 支持对应产生；该组合不
要求候选输出不可约，也不要求调用者直接提供格向量范数界。

### 严格截断循环

生产代码的系数循环提取为唯一 helper，严格模型依次原位修改每个 term 的
系数，再规范化当前多项式，最后进入下一个多项式。内循环不改变数组长度
及次数：对剩余 size-index 归纳，成功输出在 position<index 处保持输入，
其余位置是同次数与 floor(coefficient/divisor)。每步仅写 index，因而用
Array.set 的同下标和异下标性质维护公式。后续通过原多项式的次数唯一性
以及 normalization_toPoly 证明规范化后的取系数仍是原系数的 floor；不能
对可能有重复次数的任意原始 term 数组声称 floor 与求和交换。

系数桥接对规范的严格降序次数列表归纳，且可推广到任意保持零的系数函数。
若首项次数等于所查次数，则尾部次数全小于它，原始和变换后的尾部系数
都为零；若不等于，首项在该次数系数为零，直接使用尾部归纳假设。
取系数函数 c↦c/divisor，再使用 normalization_toPoly 及规范化后稀疏查找
等于数学系数，即得实际输出 sparseCoeff = 原 sparseCoeff/divisor。

## 3. 安全移除

设 b_i 为经过整数幺模行操作后的基，b_i* 为精确 Gram–Schmidt 向量。对 v=Σ c_i b_i，取最后一个非零整数系数 c_k。v 在 b_k* 上的正交系数就是 c_k，故 ||v||²≥c_k²||b_k*||²≥||b_k*||²。

若删除的整个后缀都满足 ||b_k*||²>B，则任何范数≤B 的格向量在该后缀的整数系数必须全零。否则取其最后非零系数，与上述不等式矛盾。因此其投影仍在保留行的前 r 个因子坐标张成的空间 W 中。

已有可复用的实际执行定理位于 [Refinement/Recombine.lean](../lean/CLPoly/Refinement/Recombine.lean)：`exists_last_nonzero`、`gramSchmidt_norm_le_of_last_nonzero`、`integerReducedCoordinates_reconstruct`。新增义务是从“存在某个短 GS 对角元”加强为“所有被删除尾坐标为零”，再连接新 helper 的物理输出。

## 4. 列分组与不可约性

### 从实际幺模变换直接证明分组保持原始坐标

对新 LLL 返回元组，沿初始化、主循环、收集行号三步取得同一个最终状态；
复用 initializeLLL_transform_rel / transform_unimodular 和主循环保持定理，
同时得到 M_new=U M_initial、det(U) 为整数单位以及真实 GS 缓存。
任一原始整数坐标 a 在规约基的坐标为 c=a U⁻¹，仍为整数。
integerReducedCoordinates_reconstruct 保证 c M_new=a M_initial；因此原始
向量的平方范数界经 gramPrefix_quadratic_eq_vecMul_norm 传到规约坐标。
安全移除定理推出所有被删除后缀的 c 坐标为零。又 c U=a（整数单位行列式
的逆乘法恒等式），所以若 U 在所有保留行的两列相等，则 a 的对应两坐标
相等：逐项比较有限和，保留行用列相等，删除行用 c_i=0。

此结论只要求给出初始格的实际短整数向量，不再要求调用者先假设 indicator
属于某个抽象保留空间。后续令 a 的前 r 项为真因子 indicator，尾项为模数
进位的负值，即可用于实际分组；该初始格短向量构造仍需单独连接。

实际分组接口复用已经验证的 extractCandidates_class_members_equal：先由
保留行数组的前缀性质和 U 的方阵形状推出 CandidateColumnsValid。对同一
输出组的两个成员，旧分组循环证明返回其真实源列下标及成功的逐列比较。
candidateColumnsEqual_true_sound 将比较成功转换成每个保留行的列相等，
再应用本节原始坐标定理。这里复用的是未修改的分组循环，不能复用旧的
“individual short rows”选择逻辑；传入的行数组必须来自新前缀 helper。

### 严格保留行数组的桥接

新生成模块直接实现 descending while 和分配后 iota 写入。对 iota 循环，以
`count-index` 归纳：数组长度不变；位置小于当前 index 的元素不变；从 index
到 count 的元素最终等于其位置。单步仅更新 index，由 Array.set! 的大小与
取值性质完成归纳。初始 index=0、数组长度=count，得到返回数组恰为
`0,...,count-1`。结合 retainedPrefixCount_spec，被返回数组遗漏的每一行的
GS 范数严格大于界。把这个事实代入安全移除定理，得到实际 helper 所选行
保留每一个短整数格向量，包含空数组、全保留及全删除边界。

LLL 新输出接口仍顺序调用原有 initializeLLL、lllMainLoop、collectShortRows，
仅额外导出 reduced.norms。对成功执行逐层拆分 Except，取得实际 reduced
状态，由 concreteLLLMainLoop_preserves_execution_valid 得到其 GS 关系，
输出等式保证导出的 norms 与该状态完全一致。以此实例化上述保留定理，
不允许用另行计算或由调用者假定正确的 GS norms 替代实际缓存。

矩阵追加的局部输出性质：fillCldColumnLoop 仅用 Array.set 更新已有行，
成功执行不改变外层数组长度（对 cld.size-index 归纳）。appendZeroColumn
同样保持行数，随后 push 的行就是长度 r+j+1 的零行，仅 r+j 项替换为
modulus。因此成功追加的行数恰增一，新增行最后坐标恰为实际传入 modulus；
使用 zeroMatrixRow_size、Array.getElem_set_self 和 push 的最后元素性质。
这只是局部输出性质，不能替代完整 CLD 块布局和 determinant 非零证明。

进一步证明填列循环的每个物理行：对任意 row<原矩阵行数，输出行等于原行，
唯有 index≤row<cld.size 时将指定 column 写成 cld[row] 的系数。以剩余
cld.size-index 归纳；row=index 时本步写入后递归不会再触及该行，row≠index
时本步不变。由两个 Array.set 的同下标/异下标性质和剩余区间判定完成。
失败执行不声称任何输出性质；成功分支中的边界证明保证所有实际写入合法。

对保留行的因子坐标按列相等划分 B_j。W 内任意向量在同一 B_j 内取值相等（对生成元成立，线性组合保持）。特别地，每个真因子 indicator e_g 在 B_j 内常值。故 B_j 不能同时交于两个不同真因子的支持，即 B_j 包含于某个 S_g。

完整验证从 B_j 的模乘积重构正首项本原因子 q_j，检查次数、整数精确试除以及最终余商为 1。由于原首项模 p 非零，本原化的 content 也是模 p 单位，所以 q_j 的模支持恰为 B_j。整数因子 q_j 的模支持又是若干完整 S_g 的并。非空集合 B_j 同时包含于单个 S_g、又是完整 S_g 的并，因此恰好等于那个 S_g，q_j 不可约。

该论证允许分组数小于 r，且必须检查整个分区。若验证部分失败，不接受已成功的组为完整分解。仅一个分组也服从同一证明。

## 5. 控制器终止与工程回退

本段记录过渡实现：至多三次精度尝试，每次使用全部可用列的有限倍增循环。失败时下一次提升至少达到 Mignotte 精度，并翻倍请求指数。最终未获证书时仅执行一次完整精度 Zassenhaus。2026-10-16 已删除这一控制器，改为[§43–47 的纯证书重试](vanhoeij-eventual-separation.md)，后文关于三次预算及回退来源的章节仅保留为历史证明记录。

这不等于证明“纯 van Hoeij 必在多项式精度内分离所有因子”。该更强定理仍是待办，不能借有限回退的终止性冒充；三次尝试是明确的工程回退预算，不是数学分离界。证书成功路径不依赖回退，并须用路径计数测试覆盖。

## 审核清单

验证输出本原性由实际乘积等式推出：每个返回数组成员整除该数组的
语义乘积，因此整除原始本原输入；整数多项式的本原因子定理给出该
成员本原。这不替换实际验证过程，而是消费已经证明的实际执行乘积。

新的 partitionProductLoop 同时累积次数与模乘积，其乘积分量可与
已有 trialProductLoop 建立执行投影等式。两者逐次调用相同的
multiplyNormalizeModRaw，沿实际成功运行归纳；次数累加不参与
乘积运算或下标边界。由此复用已有模乘积语义而不复制输出算法。

完整分区验证模型：逐组按实际顺序累积模乘积及 Int64 次数，调用
对称恢复、本原化和整数试除。任何组失败即返回未完成，不接受此前
已成功的前缀；末尾检查余商的物理表示恰为常数 1。全部通过才排序
并写回 factors 和 complete，保留 CLD 列数及保留行数；失败保持
原答案整体不变。实际 helper 从生产 lambda 原样提取以用于 B2B。
排序的同次数 tie 顺序未由 C++ 保证，B2B 比较因子多重集合而非其
不确定顺序；完整性证明依赖乘积及支持，不依赖 tie 顺序。

验证循环的乘积不变量为原输入等于已接受因子乘积乘 remaining。
每次实际整数试除返回空余数，由 exactDivmodRaw_toPoly 得到
remaining=factor*quotient，恰好保持 push 因子并替换 remaining 后
的不变量。终点物理常数 1 和排序排列不改变乘积。终点的 get_deg
判定需要规范表示及机器次数范围，不能单凭发生过转换的整数零值
推断数学次数为零。

乘积循环同时维持余商规范性及数学次数小于 2^63。实际 exactDivmod
返回的商由现有商规范性定理保证规范；空余数提供商整除当前余商，
当前规范非空余商非零，故商的数学次数不超过当前余商。终点由
Int64.ofNat 的合法范围及首项次数对应把 get_deg=0 还原为数学次数
零，再结合数组大小为 1、首项系数为 1 得到 toPoly=1。最终排序
只是排列，故验证成功后实际发布数组的乘积等于输入。

不可约性可不枚举全局整数不可约分解：假设某个已验证因子 q=a*b
且 a、b 都非单位。利用本原性及好素数条件保证其模像仍非单位，
实际 Hensel 支持给出 a 的非空支持 S_a。重构支持对应需证明
S_a 包含于 q 对应的组 B，且因 b 的模像非单位而为真包含。
分组定理却使 B 中的 S_a indicator 常值，非空交迫使 B 全包含于
S_a，矛盾。该路线仍必须证明物理重构支持及包含关系，不能把它们
作为未验证的输出性质直接假设。

组合 Hensel 到格向量时必须保留返回索引的真实支持等式，而不只返回
存在某个合法列表及同余。后者不足以让最终候选证明识别该向量属于哪个
真因子。组合定理同时返回合法索引、模环支持等式、前部 indicator
坐标及范数界。其支持由同一个 Hensel 唯一性见证提供，不能分别使用
两个存在性定理选取可能不同的列表。

对正次数真因子 g，输入 f 的好素数保证 f 非零，因 f=g*h 可得 g、h
均非零。实例化已证明的 integer_cld_coeff_bound，并用 h*g=f 改写
右侧，得到 H=deg(f)*2^(deg(f)-1)*sum(abs(coeff(f))) 下所有 CLD
系数的绝对值界。因此组合定理不需要额外假设 h*g' 的系数有界。
当前 H 的数学公式仍需与生产高度计算的严格模型对应，不能省略此义务。

高度 helper 严格模型保留 get_deg 到 Int32 的转换、正次数断言、
机器整数 n-1 和任意精度整数左移；L1 模型逐项复制系数、判断负号、
取负后累加。对剩余项数归纳可得任意起点的累加器结果为初值加后缀
绝对值和，进而得到实际高度输出的数组求和式。把它改写成多项式
natDegree 和各系数绝对值的公式，仍需规范表示与机器次数范围证明；
不得将次数转换直接替换成无界自然数计算。

L1 的语义桥采用逐系数绝对值多项式：规范稀疏表示的次数严格降序，
因此 coefficient-map 引理保证它的每个系数恰为原多项式相应系数的
绝对值。它在 1 处的求值一方面等于数组绝对值和，另一方面等于
原次数范围内的系数绝对值和；次数界由范围外系数全为零推出。
这样不会错误地对含重复次数的非规范数组使用 abs(sum)=sum(abs)。

机器次数桥要求规范非空输入且 natDegree(f)<2^31。由首项次数等于
natDegree，Int64 到 Int32 的转换等于 Int32.ofNat natDegree；正次数
断言给出 natDegree>0。减一仍处于有符号 32 位范围，故转整数再取
toNat 恰为 natDegree-1；任意精度整数左移等于乘以 2 的该次幂。
结合 L1 语义桥得到实际 cldBound 成功输出的数学高度公式。范围前提
须由最终入口提供，不能由成功断言推断（更大次数可能发生截断）。

CLD 执行入口用实际 Hensel 输出的 HasPhysicalOneHead 推导非空性及
首项系数为 1，用规范表示推导 HeadDominates；模数大于 1 时展开
真实 invert 实现证明首项可逆，模首一性也由 Hensel 输出推出。
原输入与提升因子的机器次数界作为明确范围条件保留，不用伪造的
整数整除前提替代。随后实际 cldPolys 运行可提供整个数组不变量。

组合入口从实际 cldBound、cldPolys、truncateCld、makeInitialMatrix
和 buildCldMatrix 成功运行推导高度公式、CLD 不变量及规范初始格，
然后调用真实因子短向量定理。返回值保留同一个合法物理索引列表的
支持等式与 indicator 坐标。输入的规范性、非空性、源次数范围及
提升因子机器次数范围仍是明确的入口前提；本入口尚不包含 LLL 执行
与候选完整验证，更不代表完整 __lll_factorize 控制器已经对应。

实际 LLL 分组连接：对真因子的 indicator 系数向量，实际 LLL 缓存
及安全保留证明保证同组两列的原坐标相等。坐标取 0/1，故这等价于
两个物理下标同时属于或同时不属于真因子支持。若实际分组有成员，
保留行必非空：空保留行会使 extractCandidates 返回空数组。生产
验证也拒绝空组数组，因此不能通过空保留集接受整个 f。

将短向量执行入口接入该结论时，先固定一个真实整数因子的同一个
支持索引见证，再对任意实际候选组及其任意两个成员应用 LLL 结论。
不能在每个组或每对成员上重新选择支持。结果仍同时保存真实因子的
模支持等式；它适用于任意正次数整数因子，不需要预先假设输出不可约。
完整验证还须证明重构因子的支持就是对应组，并利用试除及最终余商为
1 得到完整分解，当前分组定理不替代这些步骤。

实际截断格连接：以原 CLD 数组的真实 sparseCoeff 作为 raw 坐标，
从实际截断运行推出截断数组等长及系数等于 floor(raw/D)。对支持
集合的系数同余逐次数选取整数进位；向量前 r 个系数取支持 indicator，
模数行系数取负进位。原输出的 ModularCldValue 给出规范表示及绝对值
界，故可实例化已有 truncated_indicator_short，不再独立假设 raw 界
或截断系数对应。这一中间定理仍明确需要支持集合上的同余及整数 CLD
系数界，随后由 Hensel 支持与 Mahler 界提供，不冒充最终组合。

从实际 Hensel 结果获得支持：既有因子选择定理对整数因子 g 给出严格递增
合法索引列表，其模 p 乘积与 g 相伴。既有 Hensel 唯一性定理随后给出
模 p^a 等式 lc(f)*prod(selected)=lc(h)*g，其中 f=g*h。
好素数保证 lc(f) 模 p 非零，由 lc(f)=lc(g)*lc(h) 得到两个首项
系数模 p 非零；因此 lc(h) 在 ZMod(p^a) 中是单位。用单位消去
lc(h)（不可假设 ZMod(p^a) 为整环）得到 g=lc(g)*prod(selected)。
物理索引选择定义是列表下标映射，可逐项转换为实际输出数组下标。
该过程不假设整数输出不可约，也不假设提升因子在整数环整除 f。

实际 CLD 输出的系数同余到整数进位：对支持列表中的每个规范稀疏
多项式，sparseCoeff 等于其语义多项式的对应系数。取模环求和等式
两边的 degree 系数，并利用取系数与列表求和、整数到 ZMod 的映射
交换，得到 sum(C_i) 与 (h*g').coeff degree 的整数投影相等。
ZMod 的整数投影判据给出 m 整除两者之差，由整除见证取 carry，
从而 sum(C_i)=actual+carry*m。进位是从实际输出推导出的见证，
不再作为独立的正确性假设。列表版本允许重复索引；接入因子支持
时仍需另证该列表对应无重复的物理索引集合。

验证中的首项系数不变量不需要对余商再次取本原部分：实际精确除法
返回零余数即给出 remaining=factor*quotient。取首项系数并映射到
ZMod p，非零乘积的两个分量均非零。因此恢复因子和下一轮余商均
保留好素数条件。实际分组乘积循环投影到已有乘积循环之后，可复用
已证的模支持相伴与非单位结论；这里的不可约假设仅针对所选素数上
的模因子，并非整数输出因子。

完整循环的支持对应以 groups.size-index 归纳。循环不变量为当前余商
规范且首项系数模 p 非零、已有输出各自与某个物理组的选中模乘积
相伴。成功处理一组时，乘积投影和恢复支撑定理给出新增因子的相伴
关系；精确除法给出下一余商的规范性及首项系数不变量。任何拒绝分支
都与成功返回前提矛盾。循环结束时，排序是置换，因此不改变逐因子
支持关系。入口累积数组为空，故由实际成功运行推出每个返回因子的
组来源，不把“恢复结果对应组”作为调用方假设。

候选索引合法性由实际 extractCandidates 的成员来源定理导出：每个
成员都是某个小于 factorCount 的自然数转成 Int32 的结果。在明确的
factorCount≤2^31 范围内，这个转换非负且转回 Nat 为原值，所以全部
数组访问合法。保留行为空时提取结果为空，成功的完整验证入口拒绝
空分组，因而该分支不可能返回成功。由此成功入口不再需要另行假设
分组索引合法或保留行非空；机器范围条件仍须由顶层入口提供。
所选素数上的提升因子不可约性使用真实选素数/Hensel 追踪中的
selectionHenselFactors_mod_irreducible 推出；好素数首项条件来自
SelectionCorrect；模数的正性及 p 整除模数来自真实提升输出等于
p 的正整数次幂。组合入口不再把这些性质作为独立验证假设。

模支撑识别的有限乘积引理：设不同物理索引的模原子不相伴且均为素元。
某个原子整除一个索引列表上的乘积，当且仅当该索引出现在列表中。
按列表归纳，素元整除首项或尾积；前者由相伴性和物理索引唯一性
确定索引，后者用归纳假设。因此两个带相伴证据的模因子之间的整除
关系推出其物理支撑包含。这里只遍历给定有限模原子列表，不调用
整数多项式不可约分解的存在性来替代算法。
若非空真因子支撑包含在某个组内，且该组成员对真因子支撑的成员资格
一致，则取支撑中的任一点可知整组都属于该支撑。两边无重复时互相
包含给出列表置换，所以两者模乘积相等，恢复因子与该真因子的模像
相伴。这是后续排除非单位补因子的核心连接；无重复与成员一致性
仍需由实际提取、短向量和好素数输入实例化。

真实提升输出的物理原子以 Fin(output.size) 编号。所选素数上的模因子
不可约性由选素数/Hensel 来源链给出，在多项式域环中推出素性。
不同下标按大小分类，已证的调整因子互素性经 Hensel 来源及归一化
传递到实际输出；若两者相伴，则互素性迫使其中一个为单位，与模
不可约性矛盾。因此支撑识别中的不同索引不相伴可从实际执行推出。

分组支撑无重复也可从已验证输出推出：完整验证给出所有返回因子
乘积等于 f，故任意返回因子整除 f。映射到好素数后整除关系保持，
原像的无平方性传给因子；相伴关系再传给选中模原子乘积。若某个
非单位原子索引在列表中重复，则该原子的平方整除乘积，与无平方性
矛盾。这个论证无需为候选收集循环额外维护无重复不变量。
将实际 Int32 分组转为有界物理索引列表时，逐个位置保留原值的
toInt64.toNat，并使用已证合法索引界构造 Fin。列表按原位置生成，
因此不重排、不去重；其模原子乘积与实际 SelectedProductMod 相等。
这样才能把无平方性推出的无重复性用于真正的候选分组。

同组支撑一致性转移到物理列表：物理列表中的每个 Fin 成员都有一个
实际组位置，取该位置的 Int32 值即得到 CandidateMember。已有格证明
返回该值来自某个有界自然数及支撑成员等价。在 count≤2^31 的范围内
将这个值转回 Nat 恢复原下标；因此同一个等价式适用于物理列表成员。
这一转换不另行假设整数值与机器下标的对应关系。

排除非单位补因子的模论证：设已验证因子的模像 right=left*complement
无平方，left 非单位，且 left 与真因子支撑乘积相伴，right 与组乘积
相伴。left 整除 right，故它也无平方，两侧物理列表均无重复；left
非单位排除空支撑。素元支撑包含及组内成员一致性推出 left 与 right
相伴。right 非零使 left 非零，可在相伴关系中消去 left，推出
complement 与 1 相伴，即 complement 是单位。该论证只使用实际模
支撑；整数不可约性还要利用本原性及好素数把非单位整数补因子映射
为非单位，以形成矛盾。
对应的整数不可约性判据保留显式待实例化条件：每个非单位整数除数
都具有与其模像相伴、在该组内成员资格一致的物理支撑。假设一个
非平凡分解，本原性与好素数条件使两侧模像均非单位；上述模论证却
使补因子模像为单位，矛盾。该判据本身不声称这些支撑条件已由完整
控制器提供，后续必须用实际 Hensel/短向量/LLL 组合来实例化。

真因子支撑转换保留同一个索引见证：合法自然数索引数组逐位置构造
Fin 列表，其 val 列表就是原索引列表，因此成员资格和选中乘积均保持。
模数降阶先将选中提升因子的乘积视为整数多项式乘积，再用已证的
模数整除投影把模 p^a 等式降至 p；首项系数模 p 非零使该常数为
单位，消去后得到同一物理支撑上的相伴关系。不能重新选择一个模 p
支撑而丢失格证明中已经固定的成员一致性。
组合实际执行时，先从真因子短向量/分组入口取得原有合法索引及模
p^a 等式，随后仅转换这一见证。真实 Hensel 输出给出模数为 p 的
正次幂；好素数条件与 f=factor*complement 给出 factor 首项模 p
非零。完成投影和有界列表转换后，对每个实际类使用物理成员转换
引理，得到在模 p 上相伴且在每个类内成员一致的同一个支撑列表。

验证器输出非单位性由实际分支推出：空组的乘积循环不执行任何一步，
累计次数保持 0；成功验证要求累计次数大于 0，故实际接受组非空。
已有乘积执行投影与恢复模支撑定理说明其模像相伴于非空不可约模因子
乘积，所以模像非单位；整数单位映射仍为单位，故整数输出也非单位。
沿验证循环累积该性质并用排序置换保持它。
任何本原非单位整数多项式都有正次数：次数为零时它等于一个常数，
本原性迫使该常数是单位，矛盾。任意整数除数的首项系数模 p 非零
则从原多项式的首项条件及乘积分解推出。这两条事实用于把不可约性
判据中的非单位除数交给要求正次数的实际真因子支撑入口。

实际格执行加完整验证的输出不可约性组合：验证乘积等式使任意输出
因子整除 f，所以输出本原性、好素数首项条件和模无平方性均从输入
推出；输出非单位性由实际验证分支推出。该输出的物理组支撑与模像
相伴。对其任意非单位除数 g，传递整除得 g|f，本原性推出正次数，
于是实际真因子支撑入口提供同一个与 g 模像相伴且在所有类内一致的
物理支撑。取输出所属实际类，即满足不可约性判据的全部除数支撑条件。
这完成给定实际 Hensel/格/验证执行及明确机器范围和参数条件下的
乘积与逐因子不可约性；不等同于尚未建模的顶层参数选择及重试控制器。

单元素分组快速路径不需要格论证。成功验证的每个返回因子对应一个
单元素组，因此其模像相伴于一个已知不可约的模因子。本原性和首项
系数在好素数下不消失保证整数中的非平凡分解会映成两个非单位因子，
与模不可约性矛盾。该路径的证明只适用于每组恰有一个元素；不使用
输出因子数与模因子数相等来处理一般分组。

控制器单元素组构造保留 Int32 计数、比较和递增。循环条件 index<count
结合 count≤Int32.maxValue，保证 index+1 不溢出，故 toInt(index+1)=
toInt(index)+1；以 count.toInt-index.toInt 的自然数截断为递减量证明
循环终止。实际生产函数从零开始，分配 count 个空组并逐位置 push
原始 index。下一轮列数按原始 Int32 表达式 target>width/2 ? width :
2*target 建模；后续需在 0<target<width 下证明严格增长且不超过 width。
有界测试不替代机器范围内的全部证明。
单元素构造数组大小不变量由实际成功运行归纳：每轮只 set 一个组，
不改变外层数组大小；终止分支直接返回该数组。因此入口分配 count
个空组后，成功结果外层大小仍为 count。各组内容及索引合法性仍需
另行证明，不能由大小不变量推出。
内容不变量取“位置小于当前 index 的组为 [ofNat position]，其余组
为空”。每步只向当前空组 push 原 Int32 index；非负索引的机器往返
保证它等于 ofNat position。递增不溢出使边界恰前进一位，其他位置
不变。终止时 index≥count，全部合法位置都在已完成前缀中。由此实际
构造结果逐组为对应索引的单元素数组，而非预先假设单元素性质。
外层大小等于 count.toNat，故每个位置 p<count.toNat<2^31；Int32.ofNat p
非负且转回索引为 p。结合内容定理，每组只有一个合法索引。这两条
性质正是单元素快速验证不可约性入口所要求的组形状与索引条件。
构造成功性单独证明：维持 0≤index≤count 和 groups.size=count.toNat。
若 index<count，则非负和数组大小不变量保证当前访问合法，递增不
溢出且仍不超过 count；数组 set 保持大小，可归纳得到后续成功运行。
若循环结束直接返回当前数组。入口 count≥0、index=0 和复制数组大小
满足这些条件，因此存在实际成功返回，并具有已证的逐组内容性质。
快速路径组合入口以真实 Hensel 输出、计数与提升数组大小对应、实际
单元素组构造及实际完整验证成功为前提。模数正性及素数整除、模因子
不可约和首项条件从选素数/Hensel 导出；组形状和合法索引从构造导出。
最终得到乘积等于输入且每个输出不可约，不再独立假设分组为单元素。

控制器列循环单独建模，每一轮固定执行初始对角矩阵、模数行构格、
LLL、范数保留、候选提取和完整验证；不得以可选候选/结果的回调代替。
LLL 所需构格合法性只由擦除的证明参数提供，具体实例由已证的
initialized_buildCldMatrix_input_valid 构造。列数更新的证明参数也仅为
擦除的范围保持及严格递减事实，具体实例来自 nextCldTarget_progress。
循环从合法 target≤width 出发，非正时返回当前结果；验证成功立即返回；
失败且到达 width 时返回；否则实际机器整数下一列数严格增长且不超过
width，以 (width-target).toNat 递减。该有限列循环的终止不同于不断增加
Hensel 精度最终分离的终止定理，不能混淆。
每轮 bound 的 added 和输出统计保留源 Int32 转换；后续证明需要由
构格轮数界导出其无溢出，而不是把转换直接省略。
每轮成功运行的来源追踪按实际执行顺序展开 Except：任何中间 error
均与最终 ok 矛盾，因此依次取得实际初始化、构格、LLL 和提取的 ok
等式。余下等式就是对同一候选、更新后统计及原模数的完整验证运行。
保留这些中间见证可把已有不可约性组合定理应用于该实际轮次，而不
使用仅陈述最终结果正确的执行契约。
初始 complete=false 时，最终 complete=true 必须来自某一轮接受完整
验证。证明对剩余列数强归纳：不进入循环时结果仍为初始 false；每轮
验证失败只保留原因子和 complete 字段，统计更新不会改变 complete。
因此失败且达到全宽也不能产生 true；其余失败分支递归应用归纳假设。
成功分支直接提供该轮实际运行等式。该来源定理不预设输出不可约性。
构格返回列数不超过请求 target：循环保持 added≤target；只有
added<target 时才增加一列，故递归调用仍满足不变量；提前达到宽度
或达到 target 的返回都保留当前 added。入口 added=0，得到全范围界。
请求 target 为非负 Int32 时 target.toNat<2^31，因此返回列数也小于
2^31，Int32.ofNat added 的 toInt 等于 added 的整数值。count 的非负
条件和数组大小对应同样消去有符号转换，实际 bound 因而等于已有
不可约性定理要求的数学 bound。将成功来源中的同一轮执行见证逐项
代入该定理，构格合法性由具体执行实例给出，无须另加 LLL 输入合法性
假设；最终以循环来源定理提升到任意实际成功列循环。
入口参数模型保留原执行次序：先检查 m>H，再从 D=1 开始按 D*32<H
倍增；随后以 UInt64 计算 r+16 和模数位数，按源分支取 max(D,2^差值)。
倍增循环始终 D>0；循环条件推出 D<H，故 (H-D).toNat 随 D 加倍严格
减少。退出时 H≤32D。虚拟精度分支的 max 不减小原 D，因此最终 D>0。
再计算 m'=floor(m/D)，m'≤1 返回未完成；否则计算 T=ceil(H/D)+2r，
m'≤8rT 仍返回未完成。实际参数成功返回由这些分支直接给出 H<m、
D>0、m'>1 和 m'>8rT 及两个除法等式，而不额外假设这些性质。
CLD 宽度扫描保留空多项式分支、Int64 次数到 Int32 转换及 +1；这一
扫描与自然数宽度相等还需要后续无溢出证明，不能由数组长度推出。
宽度对应使用明确前提：每个非空 CLD 的首项次数加一小于 2^31。
原 get_deg 的 Nat→UInt64→Int64→Int32 转换在投影到 Int32 后等于
Int32.ofNat 首项次数；加一等于 ofNat(次数+1)，范围前提保证 toInt
精确还原该自然数。扫描归纳保持当前机器宽度为当前自然数最大值，
且该值小于 2^31。空多项式源扫描不更新，自然数扫描与零取 max，
因当前值非负，两者一致；非空时两者对同一精确宽度取 max。故实际
宽度扫描等于构格使用的 cldSpiralWidth，并得到输出非负及范围界。
入口 min(2,width) 的范围条件随之成立。这里先证明条件式对应，仍需
从输入次数和实际 CLD/截断执行推出首项范围，不能把该条件当作全入口
已经完成的证据。
完整尝试入口按实际顺序组合已有执行函数：检查计数/模数断言，计算
高度，构造和验证单元素组；失败后选择参数，计算 CLD 并截断，扫描
宽度后调用列循环。CLD/截断数组大小的已证执行性质使计数与截断后
数组大小一致；参数成功性质提供非零模数，min 的机器整数引理提供
初始列数范围。这些仅作为擦除的调用合法性证明，不能选择或替换
实际输出。计数从 size_t 转为 Int32 的范围仍以显式前提保留，后续
需要从源输入次数及 Hensel 因子数导出。
入口完成来源逐层展开实际 Except 运行：断言失败或任何辅助函数 error
都不能产生最终 ok；由成功高度和组构造取得真实见证。单元素验证返回
true 时最终结果恰是该验证输出。返回 false 时，验证器失败保持定理
说明 complete 仍为初始 false；参数选择 none 因而不能成为最终完成
结果。剩余 some 分支必须具有真实 CLD、截断及列循环运行等式，且列
循环从未完成开始。两种来源分别调用已证单元素与列循环不可约性定理。
第二分支的 H<m、D>0、m'=m/D、T 公式全部由参数选择成功规格导出，
不再作为组合入口的独立假设。
外层重试模型固定执行新的严格 Hensel 提升及新的 try-recombine，每次
覆盖当前提升数组和模数。成功立即返回因子，不检查因子数。失败时
仅 attempt<2 才检查 precision>INT_MAX/2 并计算 max(full,2*precision)；
第三次失败不再计算下一精度，循环终止后对最后一次提升调用一次严格
Zassenhaus。attempt 为 Int32，使用已证的有界递增等式，变式为
(3-attempt.toInt).toNat，故该控制器有限终止。此证明只说明有限重试
控制流终止，不能证明 van Hoeij 必然在有限提升精度获得证书。
精度更新的机器算术：当 precision≥0 且更新成功时，源检查给出
precision≤INT_MAX/2，故 2*precision 仍在 Int32 范围且整数投影精确。
因此返回值的 toInt 为 max(full.toInt,2*precision.toInt)，至少为
原 precision 和 full。大于半个 INT_MAX 时必须返回溢出 fault，不能
让机器乘法环绕。若后续要证明严格增长，还需正精度，不能只用非负。
Hensel 输出计数不依赖系数正确性：任意固定二叉提升拓扑每个缺失子树
对应一个叶因子，因此实际提取成功时追加的因子数等于内部节点数加一。
对实际提取运行按拓扑归纳，四种左右子树组合分别累计 push 或子调用的
输出大小。最终规范化只返回原数组或 set! 第零项，保持外层大小。
实际区间构造拓扑在至少两个输入因子时内部节点数为输入数减一，故从
空数组提取再规范化的输出数正好等于原输入数；原 Hensel 成功入口的
Int32 计数检查因而传递到输出。该推理不能假设返回多项式不可约。
重试成功来源按控制器变式强归纳。保持一个仅在循环已结束时需要的
前态条件：当前 lifted/modulus 来自某个实际 Hensel 成功运行。初始
attempt=0 时该条件真空成立；每轮递归时由刚完成的 Hensel 运行直接
建立。Hensel、try-recombine 或精度更新的 error 分支不可能返回 ok。
complete=true 分支记录该轮真实 Hensel 与 try-recombine 运行和最终
因子数组等式；complete=false 分支对 attempt+1 使用归纳假设。
退出分支结合前态条件，记录最后提升上的实际 Zassenhaus 运行。
因此顶层任意成功结果必来自某次实际完成验证，或某次实际提升上的
Zassenhaus；此来源定理本身不声明提升精度足够，也不声明输出不可约。
回退指数来源加强为 target≥full：维持 attempt≥1 时 precision≥full。
初始 attempt=0 真空成立。每次实际 Hensel 成功已经排除负精度，故
成功 nextPrecision 的算术定理适用，返回指数至少 full；第三次失败
不更新指数时由现有不变量保留。递归入口若已退出，则前态记录的实际
Hensel 指数亦至少 full。强归纳沿上述分支传递该条件，得到实际回退
输入来自 target≥full 的提升。此时 full 仍只是启发式返回的指数；
恢复界还要用启发式幂循环越界性质和 Hensel 输出模数界连接，不能省略。
该连接允许实际请求指数大于启发式 full，而不要求相等。成功顶层
第一次 Hensel 排除负起始精度；启发式 min 性质再给出 full 非负。
若实际请求指数为零，Hensel 自身的 Mignotte 目标已有恢复界证明。
若请求指数为正，实际 Hensel 目标是 p^target-1，输出模数严格大于
该目标，故至少 p^target。启发式幂循环给出 p^full 大于两倍首项系数
绝对值乘 Mignotte 界；由 full≤target 和 p≥2，p^full≤p^target。
合成这些不等式，再调用已有整数系数恢复界引理，建立实际输出模数
的 LiveRecoveryPrecision。此处只复用旧模块的启发式、Hensel 和恢复
数学引理，不使用旧控制器的因子数分支正确性证明。
提升因子的物理次数界可从实际输出推导：规范化后的每个 Hensel 因子
具有物理首一项，且稀疏表示规范。首一多项式模 p 后次数不变。实际
选择的模因子乘积与 f mod p 相伴，实际 Hensel 输出模 p 的乘积又与
选择乘积相伴。因此任一输出因子模 p 整除 f mod p；后者因好素数
首项系数非零而非零，整除给出次数不超过 f mod p，再由映射次数不增
得到不超过 f。规范表示的首项次数等于数学次数，从输入 degree<2^31
推出输出首项次数<2^63，不再独立假设输出次数范围。

成功提升运行，先由源断言推出输入计数与机器计数范围、非负请求指数；
源规范表示提供物理首项与数学首项的一致性，好素数选择提供调整后的
规范性、非空性、首一性和互素性。与已有递归执行就绪条件一起构成
Hensel 入口不变量，再用实际 Hensel 细化定理获得同一返回数组的语义
证书。运行确定性把存在性细化定理返回的数组与已记录数组识别。

回退分支用启发式 min 推出 full 非负，结合 target≥full 建立恢复界，
再应用实际 Zassenhaus 重组的正确性。两支均指向同一物理返回数组。
递归执行就绪仍须明确保留，不能把该条件式组装声称为无前提的运行
总正确性或纯 van Hoeij 充分精度必然成功。
