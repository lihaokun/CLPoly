# van Hoeij 真实因子短向量组合

日期：2026-10-15。目标 active，尚未合并。

## 本轮变化

新增 hensel_factor_truncated_short，在同一证明中组合：

1. 实际素数选择及 Hensel 提升的真实因子支持。
2. 同一索引见证下的实际 CLD 系数同余与进位。
3. 合法索引到格行集合的对应、基数界及求和。
4. 真实截断执行和规范格的短向量范数界。

结论同时保留合法物理索引、真实因子的模环支持等式、系数向量前部
恰为该支持的 indicator，以及实际矩阵像的平方范数界。不能分别从
两个存在性定理中选取索引而默认相同；保留支持等式还使后续分组证明
可以识别该向量所属的真因子。

正次数因子的整数 CLD 系数界由已有 Mahler 界推导，不作为调用方
前提。好素数条件给出输入非零，从因子等式推导两个乘因子非零。
目前高度值通过显式数学公式对应；实际 C++ 高度 helper 的严格模型
与该公式之间的证明仍需补齐。
