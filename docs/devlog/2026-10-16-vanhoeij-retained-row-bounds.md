# 从实际 GS 数据到保留基行整数坐标界

日期：2026-10-16。

继续[分离基础工作](2026-10-16-vanhoeij-separation-foundations.md)，新增
四项定理，从同一实际 LLL 状态的 Gram 等式推出每个保留行的平方
范数及整数坐标上界。以完整格维数 N、短向量平方 cutoff B 表示，
每个保留坐标绝对值不超过 `N·2^N·B+1`。

证明经过实际 `lllReduceWithNorms` 和后缀保留扫描，没有把 GS 范数
当作普通行范数。四项新定理和此前十五项一起构建、公理审计通过，
共 3540 jobs，十九项均只依赖标准公理。

下一步仍须从输入约束统一控制不同精度运行的 N 与 B，构造实际截断
格的小残差多项式，并接到结式及完整分组验证。本轮没有修改生产
截断参数或三次重试策略。详见[证明日志](../../proof/docs/devlog/2026-10-16-vanhoeij-retained-row-bounds.md)。
