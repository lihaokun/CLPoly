# 充分精度分离：结式及实际 GS 范数界

日期：2026-10-16。

本轮为纯 van Hoeij 终止证明补充了十项结式基础定理，以及五项实际
LLL 执行的量化界定理。十五项均通过 Lean 构建与公理审计，仅依赖
标准公理。详见[证明日志](../../proof/docs/devlog/2026-10-16-vanhoeij-separation-foundations.md)。

关键进展是：模素数幂上的首一正次共同因子使整个模数整除整数结式；
显式界 `d! B^d` 足以在充分模数下迫使结式为零。转回整数整除时处理
零残差和非单位内容，不要求残差本原。另从实际 LLL 的 size reduction、
Lovász 条件和实际后缀扫描推出保留 GS 范数的上界。

调研已核对[正式发表版](https://jtnb.centre-mersenne.org/item/10.5802/jtnb.655.pdf)
§5 的模数块、输入界决定的截断和结式论证。当前每轮重建且限制
`r+16` 位的策略仍不能直接套用其终止定理；生产参数策略本轮未改变。

下一步：把实际 GS 范数界转换为物理基行坐标界，再证明截断残差的
高度界和局部 CLD 支持条件，连接实际分组验证的成功性，并确定充分
精度信息不被丢弃的参数策略。这些仍是义务；本轮没有把有限三次回退
重新命名为纯 van Hoeij 终止证明。
