# 调整 realroot 模板定义顺序

日期：2026-10-16。

van Hoeij 全套原生回归和 FLINT 对照的公共头文件在 Clang 19 下暴露
既有编译错误：模板体构造 `uroot` 时该类型尚未完整定义。

将相同的 `realroot` 模板定义移到 `uroot` 类之后；函数体逻辑、接口
和默认参数不变。独立提交此编译前置修复，便于与因式分解算法审查
区分。三个性能版本均使用相同的定义顺序，未改历史版本的因式分解
算法。

验证：完整原生回归 27 个测试文件通过，0 失败；三版本 CLPoly/FLINT
基准均编译通过。涉及 [realroot.hh](../../clpoly/realroot.hh)。
